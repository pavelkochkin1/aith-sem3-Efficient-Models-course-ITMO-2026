# ДЗ №2: ZerO

Источник — [ZerO Initialization: Initializing Neural Networks with only Zeros and Ones](https://arxiv.org/pdf/2110.12661)

[Отчет](report.pdf): идея статьи, воспроизведение на MNIST и дополнительный опыт с Transformer.

## Что получилось

Я запускал эксперименты в Colab на Tesla T4. На основной MLP ZerO по статье получил
**98,22 ± 0,03%**, Kaiming — **98,32 ± 0,04%**. Это среднее и выборочное
стандартное отклонение трех повторов. Для контрольных вариантов — identity и полностью
нулевой инициализации — сделал по одному запуску.

Дополнительно я проверил два масштаба ZerO, чувствительность ранга к порогу,
первые шаги attention и пример из доказательства. Transformer уже был проверен в оригинальной статье, но я
попробовал эту идею на другой задаче — распознавании цифр по патчам MNIST.

## Запуск в Colab

Загрузите `reproduce.ipynb` в Colab и выполните все ячейки.
По умолчанию `RUN_TRAINING=False`: код проверит сохраненные журналы и построит
графики. Для этого не нужны GPU, скачивание MNIST или отдельные файлы.

Для нового обучения выберите GPU и задайте `RUN_TRAINING=True`.
Старые результаты сохраняются отдельно. При `DOWNLOAD_RESULTS=True`
ноутбук предложит скачать новые журналы. Настройки всех 26 запусков
находятся в [run_colab.py](run_colab.py).

## Проверки из командной строки

Из корня репозитория:

```bash
uv run --with-requirements hw2/requirements.txt python -m pytest hw2/tests -q
uv run --with-requirements hw2/requirements.txt python hw2/plot_results.py
uv run --with-requirements hw2/requirements.txt python hw2/check_theory.py
```

`plot_results.py` проверяет завершенность запусков и строит графики прямо из CSV.
`check_theory.py` считает ранг примера из доказательства. Тесты проверяют
инициализацию и первые градиенты; для запуска обучения они не обязательны.

Для отдельного обучения используйте `train.py --help` и новую папку `--output`:
скрипт отказывается перезаписывать существующие результаты. Общий `metadata.json`
сохраняется рядом с этой папкой; условия каждой группы добавляются в него отдельно.
Для MLP ранг измеряется на эпохах `0, 1, 7, 14`. Список можно задать через
`--rank-epochs`; этот флаг без чисел отключает измерение ранга в коротком пробном запуске.

## Измерения

В [results](results/) лежат результаты 12 основных MLP-запусков, двух контролей
и 12 запусков Transformer. Условия всех запусков собраны в одном
[metadata.json](results/metadata.json): параметры трех групп, списки методов и seed,
версии ПО и устройство. Каждая папка запуска содержит:

- `metrics.csv` — точность и ошибка по эпохам;
- `diagnostics.json` — первые градиенты;
- `rank.csv` — измерения ранга для MLP.

Измеряется ранг изменения весов **W₂−I**. Ранг признаков ограничен 1024 выбранными
картинками. Порог ранга указан на графиках.
